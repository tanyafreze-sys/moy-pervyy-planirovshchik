# Мой первый планировщик

«Моя неделя» - учебный планировщик целей, задач, привычек и недели.

[Открыть планировщик](https://tanyafreze-sys.github.io/moy-pervyy-planirovshchik/outputs/my-week/)

Приложение состоит из трёх файлов в `outputs/my-week/`: `index.html`, `style.css`, `script.js`. Для локального запуска скачайте репозиторий и откройте `index.html` в браузере. Сервер, сборка и установка зависимостей не требуются.

Функции - планирование недели, встречи, минимумы сфер, выполнение задач, привычки, самочувствие, история, шаблоны и ручной JSON-экспорт/импорт. Помощник использует локальные правила без API и ключей. Планировщик не гарантирует оптимальное расписание.

Данные сохраняются в localStorage браузера. На опубликованном сайте хранилище отдельное от локального файла. Для переноса скачайте JSON-копию в локальном приложении и импортируйте её на сайте. JSON не шифруется. Работайте в одной вкладке.
