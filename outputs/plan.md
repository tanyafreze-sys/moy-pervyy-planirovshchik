## Правила ведения плана

- Выполняем один этап за раз, по нумерации ТЗ от 0 до 8.
- `[x]` означает выполненный и проверенный пункт; `[ ]` - невыполненный или ожидающий проверки.
- Реализацию, автоматические проверки и проверку пользователя отмечаем отдельно.
- После этапа записываем фактический результат, ограничения и следующий шаг, затем создаём Git-коммит.
- Пользователь разрешил самостоятельно продолжать этапы. Дополнительное подтверждение для перехода не требуется; пользовательские проверки запрашиваются только при необходимости.
- Приложение находится в `outputs/my-week/` и состоит только из `index.html`, `style.css`, `script.js`.
- Этот план и ТЗ - документация, отдельные файлы приложения для запуска не требуются.
